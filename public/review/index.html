Physiologic thresholds

These belong to your medical director, not to this software. Changing them re-evaluates every loaded chart immediately. Pediatric charts are flagged rather than silently held to adult values.

All processing is local. This application has no network code path: no fetch, no XHR, no analytics, no sync. Charts and reviews are stored in this browser's IndexedDB on this device only. Use “Clear all data” when finished on a shared machine.

Automatic flags are deterministic threshold checks with citations, intended to direct attention. They are not a clinical determination and do not replace medical-director review.
